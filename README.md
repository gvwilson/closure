# Closing Time

This workshop is a short introduction to ending projects organized around a 2x2 grid:
a project either continues after the event or does not,
and the event is either gradual or abrupt.
It assumes that participants have some experience managing small projects
but little or no formal training in how to end them.
All of the material is available under an open license,
and contributions through our repository are welcome.
All participants are required to respect our Code of Conduct.
